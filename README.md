# GSU Court Finder

GSU Court Finder is a Java application for finding basketball courts near
Georgia Southern University. Users can find nearby courts, check in, and
view popular playing times.

## Features

- View basketball courts near campus
- Find nearby courts based on location
- Check in at a court
- View popular days and times
- Saves check-ins using CSV files
- JavaFX graphical interface

## Technologies

- Java
- JavaFX
- Maven
- CSS

## Run the Project

Requires Java 21 and Maven.

```bash
mvn javafx:run
```
